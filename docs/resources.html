GitHub Copilot App (2026)

Announced at Build 2026, technical preview May 14, generally available June 17, and on every Copilot plan (including Free and Education) since July 7, 2026. The app is the desktop home for agent work on macOS, Windows, and Linux, built on the same Copilot SDK runtime as the CLI and the VS Code Agent Host.

What the App Is

  • The agent-native desktop experience — find, run, steer, and land work across repos
  • github/app — downloads, release notes, issues
  • My Work: sessions, issues, PRs, and automations across connected repos in one view
  • Sessions: start from an issue, PR, or prompt; each local session runs in its own git worktree, cloud sessions run in GitHub-hosted environments
  • Canvases: plan, PR, terminal, and browser surfaces you and the agent operate on together
  • Automations: repeatable prompts as scheduled or background tasks
  • Agent Merge: the agent follows a PR through CI failures, review comments, and merge under conditions you set

Governance for the App

  • Dedicated access policy — Enabled everywhere (default), Disabled everywhere, or Let organizations decide; separate from the CLI policy
  • Enterprise managed settings — copilot/managed-settings.json in .github-private governs plugins, marketplaces, approval bypass, sandbox policy
  • MCP allowlists — allowedMcpServers / deniedMcpServers enforced in the app, CLI, and VS Code
  • Security reviews in the app — run before you land agent output
  • Framework tie-in: decide Agent Merge conditions with the agent governance template before switching it on

Customize: Skills, Plugins, MCP

  • Customize tab (GA Aug 25, 2026) — MCP servers, plugins, skills, and canvases in one place
  • Agent Plugins 1.0 — open spec (Aug 6, 2026) from Amazon, Anysphere, Microsoft, OpenAI, Vercel: plugin.json + skills/ + mcp.json
  • Agent Skills — SKILL.md folders in .github/skills, .claude/skills, or .agents/skills
  • BYOK model providers, 1M-token context window, model picker with Low/Medium/High reasoning effort

Copilot SDK & Agent Host

  • Copilot SDK — GA June 2, 2026 in Node/TypeScript, Python, Go, .NET, Rust, Java; the runtime behind the app, CLI, and IDE agents
  • VS Code Agent Host Protocol (July 2026) runs Copilot, Claude, and Codex harnesses in a dedicated process; sessions move between the app, CLI, and editor
  • Use the SDK when your team needs an internal agent with the same guardrails (custom tools, MCP, approvals) instead of a bespoke orchestration layer

Research & Data

  • Deloitte: 25% of companies running agentic pilots in 2025; 50% by 2027.
  • McKinsey: governance-first teams see +37% adoption success, -41% security issues.
  • Microsoft: productivity gains arrive after ~11 weeks of steady use.
  • GitHub Enterprise Research: structured sharing drives ~40% better outcomes.
  • Octoverse 2025: 1.13M repos importing LLM SDKs (+178% YoY); Universe 2025 launched Agent HQ, Mission Control, Custom Copilot Agents.
  • Agent HQ multi-model fleet: Anthropic, OpenAI, Google, Cognition, xAI agents on one platform via Copilot subscription.
  • Copilot app on every plan since July 2026, including Free and Education; Copilot CLI, cloud agent, and the app share one SDK runtime.
  • 2,500+ repos with agents.md analyzed — custom agents and skills becoming standard practice; Agent Plugins 1.0 (Aug 2026) shipped with support from ChatGPT, Codex, Cursor, GitHub Copilot, Kiro, and VS Code.
  • Stack Overflow surveys: 84% of developers use or plan to use AI tools, 51% daily, but only ~29% trust output accuracy (down from 40%) — the trust gap is the adoption problem to manage.
  • GitHub Rubber Duck evaluation: Claude Sonnet plus a cross-family reviewer closes ~75% of the gap to Opus alone on hard multi-file tasks — verification beats bigger models for many teams.
  • Cloud agent retrieval: 2× throughput and 37.6% better retrieval accuracy vs. early 2025; 1M-token context in VS Code, CLI, and the app.
  • AIDev (arXiv, Feb 2026): first large-scale study of AI coding agent PRs on GitHub — agent PRs need the same review discipline as human PRs, with tighter scope.
